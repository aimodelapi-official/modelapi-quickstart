# Contributing

Thanks for helping improve the ModelAPI examples.

## Before opening a pull request

- Never commit API keys, tokens, credentials, customer data, or private endpoints.
- Keep examples small, runnable, and focused on one task.
- Use environment variables for credentials.
- Test the example locally and include the command you used.

## Reporting a problem

Open an issue with the affected example, runtime version, expected behavior, and a sanitized error message. For security issues, do not open a public issue; follow `SECURITY.md` instead.
